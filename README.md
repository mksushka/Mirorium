# Mirorium

**Mirorium** is a deep fork of Git evolving into an **independent and standalone version control system**.

> ⚠️ **Important:** The project was launched recently on **October 21, 2026**. At this early stage, the codebase does not yet differ significantly from original Git. However, the roadmap focuses on a **radical architectural departure**. In future releases, Mirorium will implement its own data structures and storage formats, making it entirely **incompatible with standard `.git` repositories**.

## Project Evolution

* **Current Status:** Git-based foundation, preparing for massive core refactoring.
* **Roadmap:** Breaking free from Git's backwards-compatibility constraints to completely redesign indexing, object storage, and history management.

## Installation & Binaries

To save your time, Mirorium will be distributed as pre-compiled binaries so you won't need to install build dependencies or compile the source code manually.

* 🐧 **Linux:** Pre-compiled binaries are **not yet released** but will be published very soon in the **[Releases](https://github.com/mksushka/Mirorium/releases)** section. 
* 🪟 **Windows:** Native Windows builds are planned and will follow shortly after the initial Linux release.

## Contributing

Since the project has just started, now is the perfect time to get involved in shaping a new architecture. If you have bold ideas on how to build a version control system without the legacy constraints of Git, feel free to open Issues or submit Pull Requests!
